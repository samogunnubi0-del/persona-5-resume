# Samuel Ogunnubi — Developer Portfolio

I'm Samuel, a high school senior interested in software engineering and AI. I like building tools that solve problems I see around me, from tracking service hours to making schoolwork easier to organize.

This repository contains my interactive résumé and portfolio, with a Persona 5 / Kingdom Hearts-inspired design.

## What I'm working on

### ImpactSync · Co-founder and developer

I'm building ImpactSync with Ayomiposi Adelaja to help schools manage and verify student service hours. The project brings together student submissions, teacher and administrator workflows, and verification features. I've presented the project to school and district staff and have been improving it through their feedback.

### IsotopePINN · Student research

I explore physics-informed machine learning for modeling radioactive decay and Actinium-225 production. The research combines Python, PyTorch, numerical models, and interactive Streamlit demos. A key question is how to check model predictions against independent measurements. Numerical agreement alone is not experimental validation.

### Digital lab notebooks · School tools

I've been developing web-based notebooks for my Medical Interventions and Biomedical Innovations classes, including organized pages, data tables, graphs, and shared saving.

## About this repository

The portfolio uses **React, JavaScript, Vite, Three.js, GSAP, HTML, and CSS**. It includes animated project cards, responsive navigation, and a GitHub profile panel.

### Run locally

Requires a Node.js version supported by Vite 8.

```bash
npm ci
npm run dev
```

### Build

```bash
npm run build
npm run preview
```

### Project structure

- `src/App.jsx` — portfolio content and page sections
- `src/components/` — contact, GitHub profile, and visual components
- `src/scene.js` — Three.js scene
- `src/overlayUI.js` — interactive overlays and controls
- `src/style.css` — layout and visual styling
- `public/` — static assets
